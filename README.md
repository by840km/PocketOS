# PocketOS

Переносной рабочий стол Debian 13 / KDE Plasma с флешки внутри Windows. Windows продолжает работать под виртуальной машиной; установка на ПК и перезагрузка не нужны. Запуск пока ручной: `PocketOS\PocketOS.exe` на USB.

Текущая версия — 0.4. KDE заменяет GNOME. Оформление: Catppuccin Mocha Blue, native Breeze, Papirus Dark, плавающая нижняя панель и обои PocketOS. Источник темы и точная версия зафиксированы в `system/plasma/source.lock.json`, лицензия сохранена рядом.

Загрузчик показывает реальные этапы запуска. Сообщения BIOS/ядра закрыты его окном. Полноэкранное окно рабочего стола открывается после готовности Plasma; мгновенной загрузки ОС это не даёт. Подробности измерений и проверок — в [обновлении 0.4](docs/UPDATE-0.4.md).

Сеанс временный: базовый QCOW2 открыт только для чтения, изменения хранятся в RAM (OverlayFS, 1 GiB). Облачного сохранения пока нет. Для выхода выберите выключение питания в KDE. Извлечение USB принудительно закрывает сеанс, несохранённые изменения исчезают.

Графика по умолчанию VirGL / SDL OpenGL, до 4 vCPU и 4 GiB RAM. При ошибке запуска графики auto один раз пробует программный режим. Явный совместимый запуск: `PocketOS.exe --graphics software`. На ПК без WHPX используется TCG; его скорость отдельно не гарантируется. Интернет гостя идёт через Windows NAT.

## Разработка

```powershell
cargo fmt --all --check
cargo test --workspace --offline
.\packaging\build-portable.ps1
```

`PocketOS.exe` — графический загрузчик, `pocketos-core.exe` — Rust-процесс запуска и наблюдения за USB. Оба должны оставаться рядом. `pocketos-core.exe doctor` проверяет комплект, `plan` печатает параметры без запуска VM. Каталог dist по умолчанию содержит запускатор и документацию; QEMU и образ нужно добавить по инструкции сборки.

Собственный форк Plasma, зашифрованный профиль и интеграция облака ещё не реализованы. Модель состояний cloud-agent пока не выполняет реальные облачные операции.

## Скачать beta

[Скачать PocketOS Beta ZIP (1,8 ГБ)](https://github.com/by840km/PocketOS/releases/download/v0.4.0-beta.1/PocketOS-0.4.0-beta.1-usb.zip) — открытая загрузка без входа в GitHub.

[Релизы с ZIP](https://github.com/by840km/PocketOS/releases). Установщика нет.

1. Распаковать ZIP на USB с exFAT или NTFS (от 3 ГБ свободного места).
2. Открыть PocketOS/PocketOS.exe на флешке из Windows x64.
3. Дождаться рабочего стола KDE. Для выхода выключить PocketOS через меню KDE.

Образ Linux и переносной QEMU находятся на USB. Используются процессор, RAM и GPU компьютера; Windows работает в фоне. Linux не устанавливается на внутренний диск. Изменения гостя находятся в RAM и исчезают после выключения. Windows может использовать свой файл подкачки и системные журналы.

Перед обновлением выключить PocketOS и переименовать её прежнюю папку. Сторонние лицензии перечислены в THIRD_PARTY.md; собственный код — MIT.
