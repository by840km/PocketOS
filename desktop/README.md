# PocketOS Shell — подготовка форка

Здесь будут прямые изменения GNOME Shell, не расширение.

До копирования upstream:
1. Выбрать Debian-сборку и установить точные версии Shell/Mutter.
2. Зафиксировать source tag/commit и лицензии в upstream.lock.
3. Собрать исходную оболочку без изменений и проверить в гостевой VM.
4. Добавлять небольшими патчами панель, launcher, cloud indicator.
5. Собрать собственный deb-пакет; предусмотреть откат на исходный пакет.

Не править системную оболочку компьютера разработчика. Сейчас upstream и собственный UI отсутствуют. Визуальный дизайн согласуется до реализации.
