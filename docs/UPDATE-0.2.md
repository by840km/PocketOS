# Проверки обновления 0.2

## Сделано

1. VirGL-устройство и SDL/OpenGL вместо программного virtio VGA. Аппаратный renderer RX 570 подтверждён glxinfo (evidence/virgl-switchroot-validation.txt). Это не измерение FPS GNOME.
2. Автоматический выбор до 4 vCPU, отдельные graphics-профили и программный fallback при ошибке инициализации OpenGL.
3. switch_root с сохранением нижнего и RAM-монтов под /.pocketos вместо chroot. Устранены ошибки user namespace служб; upower active, failed units пусто.
4. Отключены автоматические фоновые проверки обновлений именно для одноразового сеанса. GNOME Software можно открыть вручную; обновления базового образа потребуют отдельного механизма релизов.
5. Windows media supervisor, native volume identity, Job Object, ограниченный сбор stderr и отсутствие orphan children.

## Автоматические проверки

11 тестов пройдено: cloud-state, аргументы запуска, программный graphics-профиль, Win32 volume identity, закрытие дочернего процесса при исчезновении источника и kill-on-job-close. Ещё один ignored test — только helper-процесс для этих проверок, не пропущенный сценарий продукта.

Release initrd проверен: switch_root присутствует, отладочного ключа нет. Доступ SSH включался только в отдельном debug initrd, в релизе SSH остаётся masked. PE removable-run-from-swap flag проверен отдельно.

Физическое извлечение USB нужно подтвердить отдельным живым тестом после установки обновления. Интервал 250 ms — частота опроса, а не гарантия времени Windows на отмену аппаратного IO.

## Ограничения

Сеанс по-прежнему volatile: извлечение USB немедленно уничтожает RAM-изменения. Облако не подключено. GNOME Shell — upstream, только настройки и служебная загрузка изменены. Полный метапакет gnome не устанавливался: он добавляет приложения, а не другой Shell. Тест 3D проведён на этом ПК с RX 570; программный fallback не обещает ту же плавность.
