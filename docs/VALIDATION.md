# Приёмка

## Автоматически сейчас

`cargo test --workspace`: параметры CLI, отсутствие raw-дисков/ISO в команде, пробелы/запятые в пути, отсутствие ложного Synced, блокирование завершения upload-фазы при ошибке/offline/очереди.

`doctor` без runtime обязан вернуть ненулевой код. `plan` обязан работать без runtime и ничего не запускать. `start` без runtime обязан отказать до запуска процесса.

## До первого запуска для пользователя

- Чистая Windows 10/11 x64, обычная учётная запись, другая буква USB.
- Каталог с кириллицей, пробелами и запятыми.
- Полный runtime и пропущенная DLL; понятная ошибка.
- TCG и реально доступный WHPX: загрузка, ввод, fullscreen, сеть.
- Исчерпание памяти и места на USB, два одновременных запуска.
- После выхода Windows и её файлы остаются доступны.

## До облачного релиза

- Запись/переименование/удаление, большие файлы и editor atomic-save.
- Сеть пропала до/во время отправки; вернулась; очередь восстановилась.
- Истёк токен, сервер вернул ошибку, заполнено облако/кэш.
- Внешняя конкурентная правка не теряется молча.
- Потеря телеметрии не превращает индикатор в «сохранено».
- Завершение при открытом редакторе и неподтверждённых записях.
- Принудительное завершение/извлечение USB тестировать только на расходных данных.

Наличие unit-тестов не подтверждает работоспособность GNOME, QEMU или облака на реальном ПК.
