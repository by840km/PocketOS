# Сборочный профиль Debian

`user-data` и `meta-data` — NoCloud-профиль для первого запуска официального Debian generic amd64 QCOW2. Это профиль разработчика: автоматический вход, данные пока не зашифрованы, собственный Shell ещё не внедрён.

1. Скачать образ и QEMU из sources.lock.json, проверить SHA512. URL latest изменяемый: при несовпадении не продолжать без обновления lock-файла после проверки источника.
2. Сделать отдельную рабочую копию QCOW2; увеличить её виртуальную ёмкость до 20G через qemu-img resize. Не использовать физические диски.
3. Установить Python-зависимость из requirements.txt в рабочее окружение и вызвать `python make-seed.py . seed.iso`.
4. Загрузить рабочую копию с seed.iso в отдельной QEMU VM. Профиль устанавливает KDE Plasma и настраивает вход пользователя pocket. Финальный пользователь этого установочного процесса не видит.
5. Дождаться `/var/lib/pocketos-image-ready`, проверить отсутствие ошибок cloud-init и работу SDDM. Маркер сам по себе не заменяет проверку рабочего стола.
6. Выключить гостя, отсоединить seed.iso. Дальнейшие обычные запуски выполняются только с установленного диска.
7. Перед публикацией очистить историю сборки, временные SSH-ключи и cloud-init instance data; отключить SSH и повторное provisioning. Сохранить список пакетов и результаты проверок отдельно.

`configure-guest.sh` — альтернативный идемпотентный шаг для управляемой сборочной VM с уже настроенным доступом. Не содержит SSH-ключей. Временные ключи текущей локальной сборки лежат только в work/, вне репозитория.

В версии 0.4 runtime использует virtio-net. Крупные пакеты при этой сборке скачивались на host, проверялись и передавались через локальный ISO: HTTPS-загрузка внутри VM могла зависать.

Графический runtime должен включать зависимости GTK/SDL и firmware. Для путей с кириллицей использовать относительный -L share. Переносной запускатор также передаёт относительный путь к гостевому диску.

make-seed.py внедряет закреплённые файлы ../plasma и configure-guest.sh в write_files; запускать профиль отдельно от этих исходников нельзя.
